The carrion ecosystem features a number of additional resources people have built.

# Profile tools

- [Cursed Toychest: Resources for Carrion](https://cursedtoychest.jcink.net/index.php?act=Pages&pid=4): an assembly of profile templates, code snippets, and chat emotes.
- [Profile Templates](https://carrion.chat/character/Profile%20Templates/): A collection of general-purpose profile code snippets.
- [Profile Templates: Novelty](https://carrion.chat/character/Profile%20Templates%3A%20Novelty/): A collection of novelty-focused profile code snippets.
- [The Gallery](https://carrion.chat/character/The%20Gallery/) / [Carrion Snippets](https://kaylasolace.github.io/Carrion-Snippets/): A collection of profile code snippets from user contributions.

# Userscripts

These extensions modify carrion's behaviour or appearance via the [tampermonkey](https://www.tampermonkey.net/) browser extension. Scripts listed here are considered safe.

None of these links point directly to a userscript install.

- [Bonnibel's carrion userscripts](https://bbbonnibel.github.io/carrion-userscripts/): A collection of very specific extensions to modify or add to your carrion experience. *(Made by carrion-strap's authors.)*

# Stylus extensions

These extensions focus on customising carrion's appearance via the Stylus browser extension. ([Chrome](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne), [Firefox](https://addons.mozilla.org/en-US/firefox/addon/styl-us/))

- [Carrion Rose](https://carrion.chat/character/Carrion%20Rose/) ([Direct link](https://userstyles.world/style/27845/)): Re-theme and repaint carrion. This userstyle is customisable.
